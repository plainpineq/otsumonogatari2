# この設計で「できること」
① common_categories を UI で自由編集
「テーマ・問い」を削除
「禁忌」「倫理観」を追加
順序変更も可能
	👉 Intent 編集UIと完全に一致

② doc_type ごとに分類を追加・削除
例：
「伏線案」を追加
「世界観ルール」を追加
「キャラ案」を削除
	👉 doc_type カスタマイズ

③ 分類の中の構成要素も編集可能
例：
シーン案に「前日譚」を追加
クライマックスを削除
「禁断の選択」など独自要素を追加
	👉 物語構造を自由に定義できる

LLM・最適化との対応
LLM生成
LLMには
	・doc_type
	・category
	・element
を明示して生成させる
例：
「小説のシーン案『事件』の候補を5案生成せよ」

# 最適化（量子アニーリング）
・element インスタンスがノード
・Intent や他要素との整合性がエッジ
・category / element はラベル情報
